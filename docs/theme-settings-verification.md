## 实现

- 从当前主题 theme.css 的 @settings 配置提取英文标题、说明和选项标签；使用宿主 YAML 解析器，不增加运行时依赖。
- 主题词典使用独立命名空间，键包含分组 ID、配置项 ID、字段及原文；通用插件词典不会覆盖 Style Settings 中的主题/片段配置区域。
- 使用可恢复的本地显示替换，折叠重新展开时重新绑定；不修改 CSS、输入值、选项 value 或配置保存事件。
- 支持恢复英文、全局暂停、补翻新增、断点续翻；翻译期间取消、主题切换、来源改变或响应失败不会覆盖已有正式词典。
- 当前主题身份使用 Obsidian 的内部 customCss.theme，已在 1.15.0 验证；Style Settings DOM 按 1.0.9 验证。无法识别配置时保留原文。
