Translate plugin and current-theme Style Settings labels into Simplified Chinese; reuse saved dictionaries offline. Version 0.5.1 keeps desktop file access separate from mobile storage. Windows Obsidian 1.11.5+ and desktop mobile emulation were tested. Android/iPhone devices and macOS/Linux are untested. Browsing sends no requests. Explicit translation sends candidate labels and, for AI, identifiers and UI context; descriptions may contain sensitive context. Notes, input values and original files are preserved. Free and open source; external services may charge. Keys use Obsidian Keychain. Desktop dictionaries remain outside the vault; mobile dictionaries/progress use the plugin configuration folder, whose sync depends on your sync settings. Desktop dictionaries are not copied to phones automatically. Configure keys on each device. Tests use simulated providers. No note translation; snippets, native menus and some dynamic controls are excluded. See README for limits.
