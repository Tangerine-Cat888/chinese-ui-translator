Translate recognizable English plugin labels into Simplified Chinese on demand. Save dictionaries for offline use, restore English at any time, and translate new labels after plugin updates. Plugin names, input values, notes and plugin source files are preserved.

Supports DeepSeek, OpenAI, OpenRouter, compatible endpoints, DeepL and self-hosted DeepLX. The plugin is free and open source; third-party services may require accounts, API keys and payment. Only explicit translation, model listing and connection tests send requests. Candidate labels and plugin ID context are sent to the chosen service. Keys are stored in plaintext in plugin data.json; dictionaries are stored outside the vault.

Desktop Obsidian 1.15.0+. Tested on Windows with a local test service. Dynamic text, native menus and some controls may remain untranslated. No note translation or mobile support. Disable the old bilingual-assistant plugin before upgrading; settings migrate once. See README for details.
